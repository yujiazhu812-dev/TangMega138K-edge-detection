# TangMega138K 实时自适应边缘检测与伪彩增强系统

基于高云 GW5AST-LV138PG484AC1/I0（TangMega 138K Dock）的实时图像处理工程。摄像头采集的 1280×720 视频经 3×3 高斯去噪、双方向 Sobel、256 桶 Otsu 自适应阈值后，可在原图、灰度、梯度、二值四种视图间实时切换，并提供以二值掩码限定着色位置、用梯度强弱决定颜色的独立 Jet 伪彩视图与红色目标框选。处理通路的参数由一帧统计得出、只在帧边界生效；显示通路的阈值偏置可随时按键调节，上行分析过程中画面不会闪烁。

## 功能特性

| 视图 | 进入方式 | 说明 |
|---|---|---|
| 原图 | 上电默认 / KEY0 短按 | 摄像头原始画面直通显示 |
| 灰度 | KEY1 短按 | RGB565 灰度提取，3×3 高斯滤波后的平滑画面 |
| 梯度 | KEY2 短按 | 双方向 Sobel 绝对值之和，8 位饱和输出 |
| 二值边缘 | USR.KEY 短按 | 以 Otsu 自适应阈值为基准的二值边缘图 |
| Jet 伪彩 | KEY1 长按 | 二值掩码限定着色位置，梯度强弱决定颜色深度 |
| 红色目标框 | KEY0 长按 | 红色分量区域框选叠加 |

- **全屏 3×3 高斯去噪**：与 Sobel 共用行缓冲，把逐点噪声在滤波后压到阈值以下，暗场景平面区不再成片误判。
- **256 桶 Otsu 自适应阈值**：对一帧非边缘点采样建灰度直方图，在有效区间内寻找类间方差最大切分点；结果只在帧边界更新，画面稳定。
- **阈值下限保护**：比较前阈值设 48 的下限，避免暗场景噪声把二值图与伪彩图铺满。
- **长按偏置**：KEY2 / USR.KEY 长按对阈值偏置以 16 为步进实时增减，HUD 同步显示阈值 T、偏置 B 与自适应标志 A。

## 硬件平台

- 主控：高云 GW5AST-LV138PG484AC1/I0，TangMega 138K Dock 底板
- 图像：OV5640 摄像头，DVP 16 位接口，J1 → Dock J9（PMOD0）、J2 → Dock J8（PMOD1），像素时钟 PCLK 约 74.25 MHz
- 存储：板载 DDR3-800，DDR3MI 控制器，400 MHz
- 输出：板载 DVI/HDMI 发送，1280×720@60 Hz（TMDS 时钟 74.25 MHz）
- 时钟：50 MHz 差分输入晶振

## 数据通路

```
OV5640 ──DVP──> 灰度提取 ──> 3×3 高斯去噪 ──┐
                                   │        ├──> Sobel 梯度 ──> Otsu 阈值 ──> 二值/伪彩
                                   └──> 红色分量统计 ──> 目标框
                                   
像素域 ──> DDR3 帧缓存（读写时钟域隔离）──> 显示域 1280×720@60Hz ──> DVI
```

跨时钟域由 DDR3 帧缓存完成，配合异步 FIFO 处理像素时钟与显示时钟的频差，长时间运行无撕裂。

## 编译与下载

1. 使用 Gowin V1.9.12.03（64 位）打开 `cam2dvi.gprj`。
2. Process → Run All，完成后码流输出到 `impl/pnr/cam2dvi.bin`。
3. 亦可直接下载仓库中的 `impl/pnr/cam2dvi.bin`。

## 按键操作

| 操作 | 功能 |
|---|---|
| KEY0 短按 | 切换到原图视图 |
| KEY1 短按 | 切换到灰度视图 |
| KEY2 短按 | 切换到梯度视图 |
| USR.KEY 短按 | 切换到二值边缘视图 |
| KEY1 长按 | 进入 / 退出 Jet 伪彩 |
| KEY0 长按 | 切换红色目标框选 |
| KEY2 长按 | 阈值偏置减小 16 |
| USR.KEY 长按 | 阈值偏置增大 16 |

## 主要指标

| 项目 | 结果 |
|---|---|
| 处理分辨率 / 帧率 | 1280×720 @ 60 fps |
| 资源占用 | LUT 81.68%、寄存器 88.30%、CLS 62.40%、BSRAM 54.25%、DSP 57.75% |
| 时序 | 50 MHz 约束下建立余量 +4.993 ns，实测最高 51.4 MHz |
| 输出延迟 | 原图 32 行、灰度 33 行、梯度 34 行、二值 35 行、伪彩 36 行 |
| 功耗 | 1.17 W |
